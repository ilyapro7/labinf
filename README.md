  # _Постановка задачи_
## 1. *Описание предметной области*
Программа создаётся для организации, чтобы навести порядок на складе техники и для удобства ее починки. Система будет отслеживать каждый компьютер, ноутбук, монитор и принтер организации. Мы всегда сможем узнать, где находится устройство: лежит на складе (свободно), выдано сотруднику или уехало в ремонт.
## 2. *Цели и задачи системы*
    - Исключить потерю техники: Все устройства привязываются к конкретным сотрудникам, поэтому они не исчезнут.
    - Убрать записи на бумаге: Заменить бумажные тетрадки и неудобные таблицы одной общей электронной базой.
    - Быстро чинить поломки: Дать сотрудникам возможность в пару кликов сообщать админам, если у них сломалась техника.
## 3. *Пользователи системы (актеры) и их роли*
    3.1. Администратор: Главный пользователь. Вносит новые компьютеры в базу, выдаёт их со склада, меняет статусы, обрабатывает заявки на ремонт. Также регистрирует новых сотрудников в базе. 
    3.2. Сотрудник организации: Обычный работник. Видит список техники, которая выдана лично ему, и может заявить о её поломке. 

## 4. *Список основных функций системы*
    - Добавление нового оборудования на складе (ввод названия, модели и серийного номера).
    - Выдача техники сотруднику (закрепление устройства за человеком в базе).
    - Просмотр техники по её серийному номеру.
    - Подача заявки на ремонт.

## 5. *Архитектура проекта*
Мы используем классическую трехуровневую архитектуру. Программа разделена на три независимых слоя:
 1. Слой интерфейса: Консольный интерфейс через который пользователь работает с системой. Программа выводит запросы, а пользователь вводит нужные данные.
 2. Слой бизнес-логики: Основа программы. Проверяет правила (например, бизнес-логика не разрешит выдать сотруднику ноутбук, если его статус в базе - Занят).
 3. Слой данных: База данных, где хранятся списки техники, людей.
